# Nexus of Curiosity

Sci-fi exploration adventure built with pure Python + Pygame. Procedural galaxies, large scrolling planets, Truth Fragments, witty AI companion ("42"), and multiple endings. Zero external assets.

Created live with **CodeGrok**.

## Quick Start

```bash
pip install -r requirements.txt
python nexus_of_curiosity.py
```

**Controls**
- WASD: Move (ship in space, walk on planet)
- SPACE: Jump (planets)
- E: Scan / collect Truth Fragments
- Mouse click: Interact / land on planets
- ESC: Back / menu

## Features (v2.2)
- Main menu, options, credits
- Procedural galaxy map (25 systems)
- Large horizontal scrolling planet levels (3000px worlds)
- Camera follow + hard boundaries (no running off-screen)
- Truth Fragment collection goal per planet
- Platform jumping + simple physics
- Alien debate dialogue encounters
- Save/load system (JSON)
- Particle effects, procedural beeps
- Color-blind mode toggle

## Running in Thonny (Beginner-Friendly)
1. Download Thonny from https://thonny.org
2. Tools → Manage packages → install `pygame` and `numpy`
3. Open `nexus_of_curiosity.py` and press Run (F5)
